# Session 1 (Nov 18–20, 2026): from web app to signed desktop app

Cloud session titled "Accessing code from emergent AI paywall". Kladde started
as a web app (an earlier Node version made with Emergent AI). In this session
it became a Tauri 2 desktop app and was released many times (up to build 37 on
Nov 18; 1.3.39 was verified for PR #13).

## Work, in order

- **Tauri port (a560df7):** React/Vite frontend kept, and `src/lib/api.ts` now
  calls Tauri commands. The Rust backend has notes, subjects, tasks, planner
  blocks, study plan, weekly summary, school import (CSV, semicolon CSV, JSON,
  copied Lectio tables) and calendar links (.ics). The data file keeps the old
  format (`kladde.json`) and is written via temp file + rename.
- **AI, first version (349c6ca):** Google Gemini free tier, with a helper chat,
  note tools (organise, summarise, explain, practice questions) and "Plan
  project with AI". It was later replaced by Cloudflare Workers AI.
- **PR #1 "Fix study workflows and build Windows and Apple Silicon editions"
  (Kladde 1.2):**
  - Apple Silicon DMG next to the Windows NSIS installer.
  - Cloudflare Workers AI for all AI features, with the token in the OS
    credential store.
  - On Mac: ChatGPT sign-in through the bundled Codex client, and Claude
    Desktop sharing through MCP (it reads one shared item and submits drafts
    the user accepts or discards).
  - Calendar fixes: Outlook/Office 365 time zone names, unknown zones treated
    as local time, and bad series skipped instead of failing the sync.
  - Overdue tasks get catch-up time in the study plan.
- **PR #2 "Signed in-app updates, reliable outside links and security
  hardening":**
  - The tauri-plugin-updater checks GitHub and installs only signed updates,
    after a click.
  - Each build is version `1.3.<run number>`, and releases include
    `latest.json`.
  - Outside links all go through the Rust `open_url` command.
  - Releases include SHA256SUMS and build attestations. npm and RustSec
    audits, CodeQL and Dependabot were added, and actions are pinned by SHA.
  - `freezePrototype` was turned on globally. This later broke the Microsoft
    login; see session 2.
- **Dependabot PRs #3–#6, #9, #10** (checkout 7, setup-node 7, upload-artifact
  7, attest-build-provenance 4, vite 8, plugin-react 6) were merged.
- **PR #12 "Fetch assignments straight from Ludus and Mit Niels Brock":**
  - "Åbn Mit Niels Brock" / "Åbn Ludus" open the school site in a separate,
    private window with no Tauri capabilities.
  - Deadline tables are read without AI. Pages without a table can be read by
    the AI, but only after a click.
  - School subject names are tidied, e.g. "1o JTP Informatik C - j26ososh" →
    "Informatik".
- **PR #13 "Fix school-window launch, note subjects, and security audit
  findings":**
  - Fixed a Windows hang when Mit Niels Brock was first opened.
  - Subjects can be created, reassigned and renamed. A rename updates notes,
    homework, planner blocks and chat history in one transaction.
  - Audit fixes: calendar fetch limits, offline saves, backup integrity and
    privacy, school-window isolation and AI consent, the Claude draft inbox.
  - CI drives the desktop app against a local fake school page. 98 Rust tests
    passed on both platforms.
  - The PR noted that production signing must move to the `release-signing`
    environment. That was done in session 2.
