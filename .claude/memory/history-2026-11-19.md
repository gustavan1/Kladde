# Session 2 (Nov 19–20, 2026): signing, Dependabot, school login, subjects

Cloud session titled "ChatGPT change merge and review", started from the iOS
app. Branch `claude/optimistic-hypatia-21tjky`. It ended with Kladde 1.3.52
released (`kladde-build-52`), all PRs merged or closed, and nothing left open.

## PRs

- **#14 "Restore release signing, show failed saves, keep 'Individuel' lessons
  in the planner":**
  - The release after PR #13 stopped at signing, because
    `KLADDE_UPDATE_SIGNING_KEY` had not been created in the `release-signing`
    environment. As a temporary fix, the job fell back to the old repository
    secret `TAURI_SIGNING_PRIVATE_KEY`.
  - Failed ticks, deletes, pins and clears now show an error toast.
  - "due" now matches only as a whole word, so "Individuel vejledning" stays a
    lesson instead of becoming homework.
  - The homework view's fallback date uses the local date instead of UTC.
- **#15 "Sign releases only with the protected environment key":** the owner
  moved the key into the main-only `release-signing` environment and deleted
  the repository secret, so the fallback was removed. README and SECURITY.md
  were updated.
- **#16 "Land the three failing Dependabot updates":**
  - **CodeQL v4:** the `init` and `analyze` steps must use the same version,
    so Dependabot now updates them as one group. Dependabot's own PR #7 was
    closed.
  - **TypeScript 7:** `baseUrl` was removed, and the `@/` alias is now a
    relative path. Dependabot's own PR #11 was closed.
  - **ureq 3:** calendar downloads and the Cloudflare request were ported, and
    the public-address-only resolver was kept. Dependabot's own PR #8 was
    closed.
- **#17:** Dependabot actions/download-artifact 8.0.2, merged.
- **#18 "Fix the Mit Niels Brock login and let students delete subjects":**
  - **Login:** Microsoft's sign-in page showed an empty white box in the
    school window. The cause was Tauri's global `freezePrototype` (on since
    Nov 18), which ran in every webview. The freeze now runs only in the main
    window, through an initialization script in `lib.rs::create_window`. The
    school window also allows `about:blank` and `about:srcdoc`. Both logins
    were checked against the real sites.
  - **Subject deletion:** "Slet fag" moves notes, homework, planner blocks and
    chat history to a subject the student picks. A subject still in use can't
    be deleted without a destination, and the last subject can't be deleted.
  - **CLAUDE.md** was added. The owner asked for it to be committed into the
    open PR.
  - The session watched #18 until CI passed, merged it, and checked that the
    release from main was published.
