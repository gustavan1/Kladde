A new Node script reads this session's observations and summaries from claude-mem.db and writes them as Markdown files that survive container cleanup.

Because it runs on every Stop, the file is refreshed after each reply, and it pairs with the existing SessionStart import (claude-mem-memory.mjs) that reads these files back in later sessions. - Each output file is capped at 60 KB (MAX_FILE_BYTES = 60 * 1024), below the 64 KB limit that the claude-mem memory import enforces.
- A redact() function replaces GitHub tokens, sk- and xox keys, AKIA keys, Bearer tokens, PEM private keys, and email addresses other than those ending in anthropic.com.
- The file is rewritten only when its content differs from what is already on disk, and the hook always exits 0 so it cannot fail the session.
